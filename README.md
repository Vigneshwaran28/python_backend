# TaskFlow Python Backend (Dual-Backend Replica for High Availability)

A high-performance, WSGI-compliant Python (Flask) backend engineered specifically for zero-downtime deployment on **PythonAnywhere** and seamless interoperability with the primary Node.js / Express backend on **Render**.

Both backends share the exact same **Neon Serverless PostgreSQL Database**, identical JWT signature logic, identical bcrypt password hashing, and RFC 6585 sliding-window rate limiters.

---

## Key Highlights & Parity Features

1. **Shared Neon PostgreSQL Database**:
   - Connects directly to Neon PostgreSQL using connection pooling (`psycopg2`).
   - Operates against the existing database tables, multi-tenant schemas, users, roles, and enterprise records.
2. **Identical JWT & Session Compatibility**:
   - Signs and verifies tokens using the exact same secret and claims (`sub`, `ws`, `sid`, `iatMs`).
   - Tokens generated by Node.js work on Python, and tokens generated by Python work on Node.js!
   - Supports cookies (`tf_session`, `tf_s_<slug>`) and Bearer headers (`Authorization: Bearer <token>`).
3. **Exact Password Hashing Compatibility**:
   - Uses standard 10-round `bcrypt` identical to Node's `bcryptjs`.
4. **RFC 6585 In-Memory Rate Limiting**:
   - Sliding-window counter matching Node.js:
     - Global API: `600 req/min`
     - Auth Endpoints: `20 req/min`
     - Public Tracking & Queue: `120 req/min`
   - Emits standard response headers: `RateLimit-Limit`, `RateLimit-Remaining`, `RateLimit-Reset`, `Retry-After`.
5. **Exact REST API Response & Error Normalization**:
   - Standard `{ "message": "...", "code": "...", "errors": { ... } }` payload.
6. **Built for PythonAnywhere Free & Paid Tiers**:
   - Native WSGI application (`wsgi.py` exporting `application`).

## Local Development Quickstart

### 1. Create a Virtual Environment
```bash
cd taskflow-python-server
python -m venv venv

# On Windows:
venv\Scripts\activate

# On Linux/macOS:
source venv/bin/activate
```

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```

### 3. Verify Environment File (`.env`)
Ensure your `.env` contains the Neon PostgreSQL connection string:
```ini
DATABASE_URL="postgresql://<user>:<password>@<neon-host>/neondb?sslmode=require"
JWT_SECRET="<your-secure-jwt-secret-here>"
PORT=5000
```

### 4. Run the Server
```bash
python app.py
```
Server will start listening at: `http://localhost:5000`

## PythonAnywhere Step-by-Step Deployment Guide

Deploying on **PythonAnywhere** takes under 3 minutes:

### Step 1: Upload Code to PythonAnywhere
1. Log in to [PythonAnywhere](https://www.pythonanywhere.com/).
2. Open a **Bash Console** from your Dashboard.
3. Clone your repository or upload the `taskflow-python-server` folder to your home directory:
   ```bash
   mkdir -p ~/taskflow-python-server
   cd ~/taskflow-python-server
   ```
   *(Or clone via git / upload as zip and unzip)*.

### Step 2: Create Virtual Environment on PythonAnywhere
In the PythonAnywhere Bash Console, run:
```bash
cd ~/taskflow-python-server
python3.10 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### Step 3: Configure the Web App on PythonAnywhere
1. Go to the **Web** tab in your PythonAnywhere Dashboard.
2. Click **Add a new web app**.
3. Choose **Manual configuration** (select **Python 3.10**).
4. In the **Virtualenv** section:
   - Enter the path: `/home/<your-username>/taskflow-python-server/venv`
5. In the **Code** section:
   - Set **Source code**: `/home/<your-username>/taskflow-python-server`
   - Set **Working directory**: `/home/<your-username>/taskflow-python-server`
6. Click the link to edit the **WSGI configuration file** (e.g., `/var/www/<your-username>_pythonanywhere_com_wsgi.py`).
7. Replace its entire contents with:
   ```python
   import sys
   import os

   # Add project folder to sys.path
   project_home = '/home/<your-username>/taskflow-python-server'
   if project_home not in sys.path:
       sys.path.insert(0, project_home)

   # Load environment variables
   from dotenv import load_dotenv
   load_dotenv(os.path.join(project_home, '.env'))

   # Import WSGI application
   from wsgi import application
   ```
   *(Make sure to replace `<your-username>` with your actual PythonAnywhere username)*.
8. Save the file.

### Step 4: Add Environment Variables
Create the `.env` file in `/home/<your-username>/taskflow-python-server/.env` with your Neon DB connection string:
```bash
nano /home/<your-username>/taskflow-python-server/.env
```
Paste:
```ini
DATABASE_URL="postgresql://<user>:<password>@<neon-host>/neondb?sslmode=require"
JWT_SECRET="<your-secure-jwt-secret-here>"
ENV="production"
```

### Step 5: Reload Web App
Click the big green **Reload <your-username>.pythonanywhere.com** button at the top of the Web tab.

Your Python API is now live at:
`https://<your-username>.pythonanywhere.com/api`

Test health endpoint:
```bash
curl https://<your-username>.pythonanywhere.com/api/health
```
Response:
```json
{
  "ok": true,
  "engine": "python-flask",
  "time": "2026-11-01T16:30:00.000Z"
}
```
